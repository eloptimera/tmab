# Treatly – Marketing AB – webbplats

Webbplats för Treatly – Marketing AB. Byggd med TanStack Start, React och Tailwind.
Designen är hämtad från jovas-projektet.

```sh
bun install
bun run dev
```

Företagsuppgifter och tjänster ligger i `src/lib/foretag.ts` och `src/lib/tjanster.ts`.
Sök efter `TODO(Treatly)` för det som ska fyllas i innan sajten går live.
